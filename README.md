# American Billing Company — Official Website

High-end, responsive corporate web application for **American Billing Company** — a premier American medical billing, physician credentialing, and revenue cycle management provider.

## 🚀 Overview & Features

- **Home Page (`index.html`)**: High-impact landing page featuring revenue cycle metrics, 360° healthcare solutions ecosystem, interactive services tab showcase, 5-point performance statistics counter, interactive ROI & cash flow recovery calculator, client testimonials, HIPAA data protection standards, and demo lead capture form.
- **About Us (`about.html`)**: Physician-led origins, client ownership philosophy, core principles, software independence, customized specialty solutions, and multidisciplinary team overview.
- **Our Approach (`approach.html`)**: Scalable practice engagement framework, assigned dedicated account managers, comprehensive 7-pillar mission, 5-point vision, and client testimonials.
- **Our Services (`services.html`)**: Detailed breakdowns of:
  - *Medical Billing & Coding*: 4 core pillars, 6 operational modules, 3-step process, and performance metrics (100% Positive ROI, 40% Cost Reduction, 150% Productivity Gains, 99% Claim Acceptance).
  - *Physician Credentialing*: CAQH registration, NPI enrollment, Medicare group contracts, and 3-phase verification checklist.
  - *Account Receivables (AR) Management*: 30-60-90-120+ days aging tracking, insurance resolution, and patient deductible management.
  - *Med-IT Live PMS Integration*: Seamless EHR/PMS synchronization with Medical Intuition Technologies.
- **Interactive Floating AI Assistant**: Persistent bottom-right interactive assistant offering quick answers regarding billing, credentialing, AR recovery, and demo scheduling.
- **Responsive Architecture**: Mobile drawer navigation, CSS Grid & Flexbox, smooth anchor scrolling, and micro-interactions.

## 💻 Local Development

Run the zero-dependency local static server:
```bash
node server.js
```
Then open `http://localhost:3000/` in your browser. Alternatively, open `index.html` directly in any web browser.
